# Contributing

Thanks for taking the time to improve Dev Context.

## Development

Install frontend dependencies:

```bash
cd frontend
npm install
```

Run the app locally:

```bash
wails dev
```

Build before submitting larger changes:

```bash
wails build
```

## Pull Requests

- Keep each pull request focused on one behavior or cleanup.
- Describe the problem, the change, and how you verified it.
- Avoid unrelated formatting or generated-file churn.
- Update documentation when behavior or setup changes.

## Reporting Issues

Include the operating system, the command or workflow you ran, the expected behavior, and the actual behavior.
